# YUVA Internship – Week 2
## Exploratory Data Analysis (EDA) and Data Visualization

### Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) and data visualization on the Netflix Movies and TV Shows dataset using Python.

The objective is to explore Netflix's content catalogue, identify patterns and trends, and generate meaningful insights through data analysis and visualizations.

### Dataset
- **Dataset:** Netflix Movies and TV Shows
- **Source:** [Netflix Dataset – Hugging Face](https://huggingface.co/datasets/hugginglearners/netflix-shows)
- **Records:** 8,807 titles
- **Original Features:** 12 columns

### Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Project Activities
1. Dataset loading and inspection.
2. Data cleaning and preprocessing.
3. Missing-value and duplicate analysis.
4. Descriptive statistical analysis.
5. Movies and TV Shows distribution analysis.
6. Country-wise content analysis.
7. Content rating analysis.
8. Genre and duration analysis.
9. Release-year and content addition trends.
10. Data visualization and interpretation.

### Key Findings
- The dataset contains 8,807 titles.
- Movies account for approximately 69.62% of the catalogue.
- TV Shows account for approximately 30.38%.
- International Movies is the most represented listed genre.
- TV-MA is the most common content rating.
- The average movie duration is approximately 99.58 minutes.

### Project Files
- Python Jupyter Notebook
- Cleaned dataset

- Data visualization charts
- Detailed project report

### Learning Outcomes
This project improved practical knowledge of data cleaning, exploratory data analysis, statistical analysis, data visualization, and extracting insights from real-world datasets.
